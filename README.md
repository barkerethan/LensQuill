# LensQuill

LensQuill empowers developers with a high-performance, multi-threaded framework for real-time compilation and context-aware processing, modularized as a server.

LensQuill is built to be simple and practical, focusing on doing one thing well.

**Why LensQuill?**

- LensQuill empowers developers with a
- high-performance, multi-threaded framework for real-time
- compilation and context-aware processing, modularized

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LensQuill.git`
2. `cd LensQuill`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
